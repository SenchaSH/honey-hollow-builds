# Honey Hollow: сборки прототипа

Прототип «Пирог Тёти Груши»: кооператив на двоих. Садовник видит уютный двор днём, Свидетель видит тот же двор ночью и правду о нём.

Здесь лежат только готовые сборки для Windows, по одной на пятницу. Скачать: раздел [Releases](../../releases), последний релиз, файл `HoneyHollow_proto_ДД.ММ.zip`.

## Как играть

1. Распакуй zip в любую папку.
2. Через Steam: оба в Steam, хост запускает `HoneyHollow.exe`, затем Играть > Создать игру > Пригласить друга.
3. Без Steam (одна сеть или Radmin VPN): оба запускают «Без Steam (по адресу).bat», друг подключается по адресу из лобби хоста.

Подробнее в файле «Как играть.txt» внутри архива. У обоих должна быть одна и та же сборка: игра с другой версией не соединится.

Игра отправляет анонимный журнал прохождения (этапы, время, финал, FPS) без имён и SteamID.
